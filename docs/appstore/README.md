### Beschreibung

```
Super Easy Budget macht genau eine Sache: dein Geld in Budgets aufteilen und Ausgaben davon abziehen. Eine Ausgabe dauert drei Tipps: Minus drücken, Betrag eingeben, Budget wählen.

SO FUNKTIONIERT ES
• Lege Budgets an, z. B. Lebensmittel, Tanken oder Freizeit, jeweils mit einem Monatsbetrag.
• Erfasse Ausgaben in Sekunden, auf Wunsch mit einer kurzen Notiz.
• Sieh auf einen Blick, wie viel du bis Monatsende noch pro Tag ausgeben kannst.

SPAREN MACHT SPASS
• Plan-Anzeige: Liegst du unter, im oder über Plan?
• Gold-Ziel pro Tag und Prognose zum Monatsende
• Monatsbilanz mit Medaillen und ein Sparschwein für übrige Beträge

ÜBERSICHTLICH
• Monatsübersicht aller Ausgaben nach Tagen
• Hell und dunkel, Deutsch und Englisch

DEINE DATEN BLEIBEN BEI DIR
• Kein Konto, keine Bankanbindung, keine Werbung, keine Tracker
• Alle Daten liegen auf deinem iPhone
• Optional: Synchronisierung über deinen eigenen Server (Selbsthosting, Anleitung auf GitHub)
• Export und Import als Sicherungsdatei

Super Easy Budget ist ein kostenloses Open-Source-Projekt.
```

## English (U.K. und U.S.)

### Name

```
Super Easy Budget
```

### Untertitel

Envelope budgets in 3 taps

### Werbetext

```
Create budgets, log expenses in one tap and see how much you can still spend per day. No account, no bank connection, no ads.
```

### Schlüsselwörter

```
expense tracker,envelope,spending,money,savings,allowance,offline,simple,daily,planner
```

### Beschreibung

```
Super Easy Budget does one thing: split your money into budgets and subtract what you spend. Logging an expense takes three taps: press minus, enter the amount, pick the budget.

HOW IT WORKS
• Create budgets such as groceries, fuel or fun, each with a monthly amount.
• Log expenses in seconds, optionally with a short note.
• See at a glance how much you can still spend per day until the end of the month.

SAVING MADE FUN
• Plan indicator: are you under, on or over plan?
• A daily gold target and an end-of-month forecast
• A monthly review with medals and a piggy bank for leftovers

CLEAR OVERVIEW
• Monthly overview of all expenses by day
• Light and dark mode, English and German

YOUR DATA STAYS WITH YOU
• No account, no bank connection, no ads, no trackers
• All data is stored on your iPhone
• Optional: sync through your own server (self-hosted, instructions on GitHub)
• Export and import a backup file

Super Easy Budget is a free open-source project.
```

## Hinweise für die Prüfung (App Review Notes, Englisch)

```
No sign-in is required. All data is stored locally on the device.

To test: tap "Create your first budget", enter a name and a monthly amount, save. Then tap the round minus button, enter an amount, pick the budget and tap "Deduct". Tap the top card to see the monthly overview.

Sync (Settings → Sync) is optional and connects only to a server the user hosts themselves (open source, see the support URL). The app is fully functional without it, so no demo server is provided.
```
